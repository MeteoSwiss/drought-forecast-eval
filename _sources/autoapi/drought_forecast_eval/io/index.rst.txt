.. py:function:: load_forecasts(archive_dir: str | pathlib.Path, date_range: tuple[str, str] | None = None, region_ids: list[int] | None = None) -> xarray.Dataset

   Load forecast data from a flat directory of ZIP archives.

   Each ZIP is expected to contain ``weekly_forecast_regions.csv``.
   The ``forecast_reference_time`` is parsed from the ZIP filename
   (``YYYYMMDD`` block).

   :Parameters: * **archive_dir** -- Path to the flat directory containing the daily ZIP files.
                * **date_range** -- Optional ``(start, end)`` ISO-date strings (inclusive).
                * **region_ids** -- Optional list of ``drought_region_id`` integers to keep.
                  ``None`` returns all 38 regions.

   :returns: Dimensions: ``(forecast_reference_time, drought_region_id, lead_week)``
             Coordinates: ``forecast_reference_time``, ``drought_region_id``,
                          ``lead_week`` (int 0–3), ``valid_at`` (derived datetime).
             Variables: all forecast columns from ``FORECAST_SCHEMA``.
   :rtype: xr.Dataset

   :raises FileNotFoundError: If ``archive_dir`` does not exist.
   :raises SchemaError: If a CSV is structurally invalid.
   :raises RuntimeError: If no valid ZIP files are found.

   :rtype: xr.Dataset

   :raises FileNotFoundError: If the path does not exist.
   :raises SchemaError: If the CSV is structurally invalid.


.. py:function:: scan_archive(archive_dir: str | pathlib.Path, date_range: tuple[str, str] | None = None, region_ids: list[int] | None = None) -> list[tuple[datetime.datetime, pathlib.Path]]

   Scan a flat directory and return sorted (forecast_reference_time, path) pairs.

   Only files matching the expected filename pattern are returned.  If multiple
   ZIPs share the same date (e.g. re-runs), only the lexicographically last one
   is kept (highest HHII suffix → most recent run of that day).

   :Parameters: * **archive_dir** -- Path to the flat directory containing ZIP files.
                * **date_range** -- Optional ``(start, end)`` ISO-date strings (inclusive on both ends).
                  If ``None``, all available ZIPs are returned.
                * **region_ids** -- Unused at this layer; accepted for API symmetry so callers can pass
                  region selection once and forward it unchanged.

   :returns: Sorted ascending by forecast_reference_time.
   :rtype: list of (datetime, Path)

   :raises FileNotFoundError: If ``archive_dir`` does not exist.


.. py:function:: download_archive(dest_dir: str | pathlib.Path, start: str | datetime.date | datetime.datetime | None = None, end: str | datetime.date | datetime.datetime | None = None, overwrite: bool = False) -> list[pathlib.Path]

   Download daily rolling archive ZIPs from BGDI.

   Iterates every calendar day in ``[start, end]`` and tries to fetch the
   corresponding ZIP.  Missing days (404s) are silently skipped — not every
   day has a published archive.

   :Parameters: * **dest_dir** -- Local directory where ZIPs will be stored (flat layout).
                * **start** -- First date to download.  Defaults to yesterday.
                * **end** -- Last date to download (inclusive).  Defaults to today.
                * **overwrite** -- Re-download files that already exist locally.

   :returns: Paths of successfully downloaded files.
   :rtype: list of Path


.. py:function:: download_historic(dest_path: str | pathlib.Path, overwrite: bool = False) -> pathlib.Path

   Download the full historic observation archive from BGDI.
