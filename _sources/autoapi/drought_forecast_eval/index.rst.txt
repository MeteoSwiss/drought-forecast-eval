drought_forecast_eval
=====================

.. py:module:: drought_forecast_eval

.. autoapi-nested-parse::

   drought-forecast-eval: Verification library for Swiss drought forecasts.

   Public API
   ----------
   Data loading
       load_forecasts      -- parse flat ZIP archive → forecast xr.Dataset
       load_observations   -- parse historic ZIP → observation xr.Dataset

   Processing
       align_obs_to_forecast    -- merge obs onto forecast grid
       climatology_reference    -- week-of-year climatology reference forecast
       persistence_reference    -- last-observed-value reference forecast

   Scoring
       compute_scores           -- dispatch all scores → result xr.Dataset
       register_score           -- add a custom metric to the registry

   Reporting
       ReportBuilder            -- orchestrate full pipeline → NC/HTML/CSV output

   .. rubric:: Examples

   >>> from drought_forecast_eval import load_forecasts, load_observations
   >>> from drought_forecast_eval import align_obs_to_forecast, compute_scores
   >>> from drought_forecast_eval import ReportBuilder
   >>>
   >>> ds_fcst = load_forecasts("path/to/zips", date_range=("2025-01-01", "2025-12-31"))
   >>> ds_obs  = load_observations("path/to/historic.zip")
   >>> ds      = align_obs_to_forecast(ds_fcst, ds_obs)
   >>> ds_scores = compute_scores(ds)
   >>> ds_scores.to_netcdf("scores.nc")

.. py:function:: load_forecasts(archive_dir: str | pathlib.Path, date_range: tuple[str, str] | None = None, region_ids: list[int] | None = None) -> xarray.Dataset

   Load forecast data from a flat directory of ZIP archives.

   Each ZIP is expected to contain ``weekly_forecast_regions.csv``.
   The ``forecast_reference_time`` is parsed from the ZIP filename
   (``YYYYMMDD`` block).

   :Parameters: * **archive_dir** -- Path to the flat directory containing the daily ZIP files.
                * **date_range** -- Optional ``(start, end)`` ISO-date strings (inclusive).
                * **region_ids** -- Optional list of ``drought_region_id`` integers to keep.
                  ``None`` returns all 38 regions.

   :returns: Dimensions: ``(forecast_reference_time, drought_region_id, lead_week)``
             Coordinates: ``forecast_reference_time``, ``drought_region_id``,
                          ``lead_week`` (int 0–3), ``valid_at`` (derived datetime).
             Variables: all forecast columns from ``FORECAST_SCHEMA``.
   :rtype: xr.Dataset

   :raises FileNotFoundError: If ``archive_dir`` does not exist.
   :raises SchemaError: If a CSV is structurally invalid.
   :raises RuntimeError: If no valid ZIP files are found.

   Load the full observation archive from the historic ZIP.

   :Parameters: * **historic_path** -- Path to the historic ZIP file (``weekly_historic_regions.csv.zip``)

   :returns: Dimensions: ``(drought_region_id, valid_at)``
             Variables: all observation columns from ``OBSERVATION_SCHEMA``.
   :rtype: xr.Dataset

   :raises FileNotFoundError: If the path does not exist.
   :raises SchemaError: If the CSV is structurally invalid.


.. py:function:: align_obs_to_forecast(ds_fcst: xarray.Dataset, ds_obs: xarray.Dataset) -> xarray.Dataset

   Merge observations onto the forecast ``(frt, region, lead_week)`` grid.

   :Parameters: * **ds_fcst** -- Forecast dataset with dims ``(forecast_reference_time, drought_region_id,
                  lead_week)`` and coordinate ``valid_at``.
                * **ds_obs** -- Observation dataset with dims ``(drought_region_id, valid_at)``.

   :returns: The forecast dataset with observation variables appended under the
             suffix ``_obs``.  Dimensions remain
             ``(forecast_reference_time, drought_region_id, lead_week)``.
   :rtype: xr.Dataset

   :raises ValueError: If ``ds_fcst`` is missing the ``valid_at`` coordinate.


.. py:function:: climatology_reference(ds_obs: xarray.Dataset, ds_fcst: xarray.Dataset, week_window: int = 4) -> xarray.Dataset

   Build a climatological reference forecast on the forecast grid.

   For each target ``valid_at`` (Monday), collect all historical
   observations within ±``week_window`` ISO-weeks of the same week-of-year
   across all available years.  Return p10 / p50 / p90 of that sample as
   the probabilistic reference forecast.

   :Parameters: * **ds_obs** -- Observation dataset with dims ``(drought_region_id, valid_at)``.
                * **ds_fcst** -- Forecast dataset used only for its grid coordinates
                  ``(forecast_reference_time, drought_region_id, lead_week, valid_at)``.
                * **week_window** -- Half-width of the week-of-year window (inclusive).  Default 4 means
                  ±4 ISO weeks around the target week are included in the sample.

   :returns: Dimensions ``(forecast_reference_time, drought_region_id, lead_week)``.
             For each observation variable ``v`` the dataset contains
             ``v_ref_p10``, ``v_ref_p50``, ``v_ref_p90``.
   :rtype: xr.Dataset


.. py:function:: persistence_reference(ds_obs: xarray.Dataset, ds_fcst: xarray.Dataset) -> xarray.Dataset

   Build a persistence reference forecast on the forecast grid.

   For each ``forecast_reference_time`` and ``drought_region_id``, the last
   observed value **strictly before** the ``forecast_reference_time`` is used
   as the flat reference across all lead weeks.

   :Parameters: * **ds_obs** -- Observation dataset with dims ``(drought_region_id, valid_at)``.
                * **ds_fcst** -- Forecast dataset used for its grid coordinates.

   :returns: Dimensions ``(forecast_reference_time, drought_region_id, lead_week)``.
             For each observation variable ``v`` the dataset contains
             ``v_ref_p50`` (persistence is deterministic, stored as p50 for
             consistency with the climatology reference interface).
   :rtype: xr.Dataset

.. py:function:: compute_scores(ds: xarray.Dataset, variables: list[str] | Literal['all'] = 'all', scores: list[str] | Literal['default'] = 'default', ds_ref: xarray.Dataset | None = None, cdi_threshold: float = 2.0, output_path: str | pathlib.Path | None = None, variable_map: dict | None = None) -> xarray.Dataset

   Compute verification scores for all requested variables.

   :Parameters: * **ds** -- Merged dataset from
                  :func:`~drought_forecast_eval.processing.alignment.align_obs_to_forecast`.
                  Must contain both forecast and observation variables.
                * **variables** -- List of variable keys from ``VARIABLE_MAP`` (e.g. ``["spi_1m", "cdi"]``),
                  a group name (``"precipitation"``, ``"streamflow"``, ``"soil_moisture"``,
                  ``"cdi"``), or ``"all"`` to score everything.
                * **scores** -- List of metric names from ``SCORE_REGISTRY``, or ``"default"`` which
                  expands to ``["mae", "rmse", "bias", "correlation"]`` plus quantile
                  metrics for quantile-mode variables.
                * **ds_ref** -- Optional reference forecast dataset (from
                  :func:`~drought_forecast_eval.processing.reference.climatology_reference`
                  or :func:`~drought_forecast_eval.processing.reference.persistence_reference`).
                  Required for ``"mae_skill"`` and ``"rpss"``.
                * **cdi_threshold** -- Threshold for binary drought event used in ROC-AUC.  Default 2.
                * **output_path** -- If provided, the result dataset is written to this NetCDF4 path.
                * **variable_map** -- Override the global ``VARIABLE_MAP``.  Useful for custom experiments.

   :returns: Dimensions: ``(lead_week, drought_region_id)``.
             Variables: ``{var_key}_{metric}`` for every computed score.
             Global attributes record the computation parameters.
   :rtype: xr.Dataset

   :raises ValueError: If none of the requested variables are present in the dataset.
