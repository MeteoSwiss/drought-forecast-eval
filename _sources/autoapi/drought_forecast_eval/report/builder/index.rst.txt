drought_forecast_eval.report.builder
====================================

.. py:module:: drought_forecast_eval.report.builder

.. autoapi-nested-parse::

   ReportBuilder: single-entry-point orchestrator for the full pipeline.

   Usage
   -----
   >>> builder = ReportBuilder(
   ...     archive_dir="/data/zips",
   ...     historic_path="/data/historic.zip",
   ...     date_range=("2025-01-01", "2025-12-31"),
   ...     output_dir="./output",
   ... )
   >>> builder.run()                     # → output/scores.nc + output/report.html
   >>> ds_scores = builder.compute_scores()   # just scores, no I/O

.. py:class:: ReportBuilder(archive_dir: str | pathlib.Path, historic_path: str | pathlib.Path, date_range: tuple[str, str], regions: list[int] | Literal['all'] = 'all', variables: list[str] | Literal['all'] = 'all', scores: list[str] | Literal['default'] = 'default', reference: Literal['climatology', 'persistence', 'both'] = 'climatology', cdi_threshold: float = DEFAULT_CDI_THRESHOLD, shapefile_path: str | pathlib.Path | None = DEFAULT_SHAPEFILE, output_dir: str | pathlib.Path = './output', week_window: int = DEFAULT_WEEK_WINDOW, variable_map: dict | None = None)

   Orchestrate the full verification pipeline.

   :Parameters: * **archive_dir** -- Flat directory of daily forecast ZIP archives.
                * **historic_path** -- Path to the historic observation ZIP (or CSV).
                * **date_range** -- ``(start, end)`` ISO-date strings for the verification window.
                * **regions** -- ``"all"`` or a list of integer region IDs.
                * **variables** -- ``"all"``, a group name, or a list of variable keys.
                * **scores** -- ``"default"`` or a list of metric names.
                * **reference** -- Which reference forecast strategy to use: ``"climatology"``,
                  ``"persistence"``, or ``"both"``.
                * **cdi_threshold** -- Binary event threshold for CDI ROC-AUC.
                * **shapefile_path** -- Path to the drought-region shapefile for map plots.
                * **output_dir** -- Directory where all output files are written.
                * **week_window** -- Half-width of the climatology week-of-year window (weeks).
                * **variable_map** -- Override the global VARIABLE_MAP for custom experiments.
