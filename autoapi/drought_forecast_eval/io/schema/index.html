drought_forecast_eval.io.schema#

Schema definitions and validation for forecast and observation CSV files.

Both schemas are defined as dicts mapping column name → expected pandas dtype. Validation emits warnings on unexpected columns (forward-compatibility) and raises SchemaError on missing required columns or unparseable types.
